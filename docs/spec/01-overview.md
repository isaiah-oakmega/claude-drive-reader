# 01 專案概述

## 背景

- 性質：OakMega 招募流程第二輪（Round 2）Take-Home Assignment。
- 題目：**Claude Code Plugin：Google Drive Reader**
- 一句話目標：開發一個 Claude Code plugin，讓使用者能透過**自然語言**存取**指定 Google Drive 資料夾**中的內容。

## 基本條件

| 項目 | 內容 |
|------|------|
| 期限 | **兩週**，繳交期限 **2026-11-23（一）**（出題方來信） |
| 交付形式 | **GitHub Repo** |
| 完成標準 | **讀取成功即算完成** |

## 出題方來信的額外要求

出題方另以信件補充（原作業說明未載）：

- 完全開放、甚至推薦使用 AI 完成。
- **建議在 repo 中多記錄內容**，以便評斷 → 決策紀錄（`docs/adr/`）、名詞表（`CONTEXT.md`）、架構說明都是評分素材。
- **[必要] C-1**：server 須以 **Django / Flask / FastAPI** 任一撰寫。→ 採保守解讀：web 後端（Token Broker）以三者之一撰寫，本機 MCP server（stdio）也以 Python 撰寫，任何一種「server」的解讀都滿足。
- **[必要] C-2**：須能**清楚說明每一行邏輯的功用與技術取捨**。→ [推論] 程式碼應精簡、依賴少、避免難以解釋的框架魔法；非顯而易見的取捨要在程式註解或 ADR 中交代。
- 有問題可來信詢問出題方。

## 核心能力（摘要，細節見 [02 功能需求](02-functional-requirements.md)）

1. 透過 OAuth 完成 Google 帳號授權
2. 列出指定資料夾內的檔案（含子資料夾）
3. 讀取檔案內容，並回應使用者的自然語言提問

## 範圍界定

> 本次驗收只要求「讀取」成功即可 — 不需要支援搜尋、寫入、監聽變更等進階功能。把資源集中在把 OAuth 流程與讀取路徑做穩、做對。

- 優先順序：**OAuth 流程的穩定與正確 ＞ 讀取路徑的穩定與正確 ＞ 其他一切**。
- 明確不需要做的事：搜尋、寫入、監聽變更（詳見 [02 非目標](02-functional-requirements.md#非目標out-of-scope)）。

## 考核重點之一：獨立建立授權鏈路

> OAuth Client、redirect URI、後端服務（若需要）都由你自己申請、自己架設、自己部署。我們不提供任何正式環境的 credentials 或伺服器 — 這也是這次要考核的一部分：你怎麼設計並獨立跑起這整條授權鏈路。

- 整條授權鏈路（OAuth Client → redirect URI → callback／token 交換 → token 保存）的**設計與獨立部署能力本身就是考核項目**。
- 細節見 [04 環境與前置準備](04-environment.md)。

## 評估哲學

- 看的是 OAuth 流程是否**順暢、安全**，以及讀取路徑是否**穩定**。
- **不是看程式碼的量。**
