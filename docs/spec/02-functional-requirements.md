# 02 功能需求

## 產品形態

- **[必要]** 產出物為一個 **Claude Code plugin**。
- **[必要]** 可包含 MCP server 實作（原文交付清單寫「plugin + 任何 MCP server 實作」，代表 MCP server 是預期中的常見做法，但未強制）。
- **[必要]** 使用者透過**自然語言**與 Claude 互動來操作，而非直接呼叫指令／API。

## FR-1 OAuth 授權

- **[必要]** 透過 **OAuth** 完成 **Google 帳號**授權。
- **[必要]** 驗收者會「完成一次完整的 OAuth 授權」，流程必須能由沒看過程式碼的人依 README 獨立完成。
- **[必要]** 評估重點：流程是否**順暢**、是否**安全**。
- **[必要]** OAuth Client、redirect URI、後端（若需要）全部自行申請、架設、部署（見 [04](04-environment.md)）。
- **[建議]** 授權失敗時要有清楚的錯誤訊息（見 [07](07-non-functional.md)）。

## FR-2 列出資料夾內檔案

- **[必要]** 列出**指定資料夾**內的檔案。
- **[必要]** **含子資料夾**（子資料夾本身與其中內容都需能被列出／存取）。
- **[必要]** 驗收方式：用自然語言請 Claude「列出資料夾內的檔案」。
- 指定資料夾 = 出題方提供的測試資料夾（見 [03](03-test-data.md)）。

## FR-3 讀取檔案內容並回應提問

- **[必要]** 讀取檔案內容。
- **[必要]** 依讀到的內容回應使用者的**自然語言提問**。
- **[必要]** 驗收方式：用自然語言請 Claude「讀出檔案的內容」。
- **[必要]** 讀取路徑需**穩定**。
- **[必要]** 須能處理非原生 Google 格式（PDF）與無法直接抽取文字的檔案（圖片），處理方式見 [03](03-test-data.md#檔案類型處理要求)。

## 非目標（Out of Scope）

以下功能**不需要**支援，不應為此投入資源：

| 項目 | 狀態 |
|------|------|
| 搜尋 | 不需要 |
| 寫入（新增／修改／刪除 Drive 檔案） | 不需要 |
| 監聽變更（watch／push notification／同步） | 不需要 |

> 原文：「把資源集中在把 OAuth 流程與讀取路徑做穩、做對。」
